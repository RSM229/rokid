### 4.2 启动时序（`app/main.py` lifespan）
1. `check_production_security()` → 生产配置告警；严格模式下失败即拒绝启动
2. `init_db()` → 建表 + 启动期 `ALTER TABLE ... ADD COLUMN` 非破坏补齐
3. RAG 预热（`asyncio.to_thread(rag.warmup)`）——**失败不阻塞启动**，检索自动降级为关键词模式
4. 拉起三个守护协程：
   - `rtc_service.timeout_worker()` — RTC 会话超时回收
   - `rag_index.incremental_worker()` — 索引增量刷新
   - `period_report_service.daily_report_worker()` — 每日 08:00（东八区）自动生成前一日监理日志，遇周日/月末补周报/月报（幂等，不覆盖已复核草稿）
5. 关闭时依次 cancel 协程 + `close_db()`

## 6. AI 与算法能力层

### 6.1 模型调用（token-plan 端点，必须「端点 + 套餐内模型名」配对）
| 能力 | Provider | 端点 / 模型 |
|---|---|---|
| LLM（文本） | dashscope | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` · 默认 `qwen3.7-plus` |
| STT（语音识别） | dashscope | 同端点 · `qwen-audio-3.0-asr-flash` |
| TTS（语音合成） | dashscope | 同端点 · `qwen-audio-3.0-tts-plus` · 音色 `longanlingxi` |
| VLM（隐患识别） | 华工（AI Center） | `https://ai.sentripy.cn/api/v1/tools/hazard_vlm_detection/invoke-upload` · `hazard_vlm_detection` |

> 套餐内 16 个可选模型：qwen3.7-max/plus、qwen3.6-flash、qwen3.8-max/flash、glm-5.2/5.3、deepseek-v4-pro、deepseek-v4-flash-0731、deepseek-v4.1-flash、wan2.7-image(-pro)、qwen-audio-3.0-tts/realtime-plus、auto、decision-model-preview。
> 小程序端「模型」下拉有 3 项（千问3.7 Max / 3.7 Plus / 华工），经 `/api/local/llm/chat` 的 `provider` / `model` 参数切换。
> 运行时模型配置亦可经 `/api/model-settings` + `model_configurations` 表动态管理。

### 6.2 RAG 检索（生产可用）
- 嵌入：本地 ONNX `bge-small-zh-v1.5`（约 95MB），分词 jieba，无需 GPU / 外部 API
- 融合策略：**三路字段化 RRF** —— BM25 + 向量 + 标题块，三路**各自独立排名**后融合；`TITLE_CHUNK_WEIGHT = 3.0`
  - 设计铁律：要让某路信号起作用必须做独立一路，不能用「加分」——加分会被多路命中稀释且打乱序
- 索引维护三层：BackgroundTasks 即时 / `incremental_worker` 守护 / CLI `scripts/build_rag_index.py --force`
- 评测：`scripts/eval_rag.py`，历史指标 Recall@5 = 100%、MRR = 0.878（605 块口径；线上实际 607 块，未重跑）
- 语料表：`kb_chunks`、`regulation_chunks`（`embedding` 列为 BLOB）

### 6.3 文书生成
- `doc_generator` + `form_renderer` + `ledger_exporter`
- 依赖：`reportlab`（PDF）、`python-docx`（DOCX）、`openpyxl`（XLSX）、`pypdf`
- 字体：`app/fonts/`（中文 PDF 必须内嵌）
- 输出落 `exports/`，经 `/exports/` 静态暴露
- 省统表：`provform_schema.py`（32 个表单编号）+ `form_doc.py` 路由

## 8. 关键数据流

**A. 现场隐患闭环**
```
眼镜/小程序拍照 → /api/media 上传（uploadQueue 断网重传）
→ 华工 VLM 识别 → hazards 落库 → 生成 rectifications 整改单
→ issue_tickets 派单 → /api/ws 推送通知 → 小程序待办
→ 整改回复 → 归档 archive_records / 台账 ledger_archives → 导出 PDF/DOCX
```

**B. 语音问询**
```
眼镜录音（Rokid SDK）→ /api/local/stt/transcribe 或 /api/omni/stt
→ RAG 三路检索（规范 + 知识库）→ LLM 生成 → TTS 播报
```

**C. 会话式工作记录**
```
/api/work-session/* 建会话 → 语音/文本增量录入
→ 完成时 WorkRecordService 汇总 → work_records 落库 → 周期文书自动成稿
```

## 10. 项目权限边界（2026-10-09 上线）

- `ProjectMember` + `SecurityAudit`（表名单数：`project_members` / `security_audit`）
- 项目 list 仅返回成员项目；`admin`（`username == "admin"`）返回全量；switch 非成员项目 → 403 + 写审计
- `users.project_id` 仅表示「当前上下文」，真实归属看成员表 → **任何修改 `project_id` 的位置必须同步成员行**
- 审计写入函数 `_write_audit` 是同步 `def`，调用处**勿加 await**

## 11. 已知边界与风险（架构层面）

| 级别 | 项 | 说明 |
|---|---|---|
| 高 | SSO 替换登录主干 | 若接入外部平台（穗建通），`request.ts` token 链路 + login/register 页 + 自建账号映射需整体改造，风险高于任何加功能 |
| 中 | 无回写通道 | `provform.py` 仅 3 个只读接口，无回写端点，依赖平台提供 |
| 中 | `media_segments.py` 未注册 | 路由代码在位但未挂载 |
| 中 | 全站无 `load_dotenv` | 所有环境变量只能来自 compose / 容器环境，`.env` 文件不生效 |
| 低 | 线上 nginx conf 与本地副本不一致 | 本地 `server_name` 为 `mybaize.com` |
| 低 | RAG 评测数未同步 | 线上 607 块 vs 评测 605 块 |
| 低 | 同名文档 DB 层重复 | 索引层遗留 |
