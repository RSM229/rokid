# 监理通 使用说明书

**版本**：v1.0（2026-10-10）
**适用对象**：① 监理人员（项目级岗位）② 管理员（超管/管理员/总监）③ 对外汇报/交付
**系统组成**：Web 管理后台 + 微信小程序（数据实时同步，同一账号两端通用）

---

# 第一部分 · 快速上手（全员必读）

## 1.1 系统是什么

监理通（白泽）是 AI 工程监理智能体：

- **Web 管理后台**：https://www.baize.gdces.cn/admin/ （管理与看板为主）
- **微信小程序**：微信内搜索或扫码（现场作业为主）

两端数据实时同步：小程序现场填报的巡视/隐患，Web 端即刻可见。

## 1.2 账号从哪里来

| 方式 | 说明 |
|---|---|
| 管理员发放邀请码 | **主要方式**。向超管要邀请码 → 小程序/网页注册 → 岗位由邀请码决定 → 管理员把你分配到项目 |
| 管理员直接建号 | 超管在「用户管理 → 新增用户」直接创建，把账号密码给你 |

> 注册三要素：用户名、真实姓名、**邀请码**（必填）。密码至少 8 位。

## 1.3 登录

### 小程序（推荐日常使用）
1. 打开小程序 → 点「微信一键登录」
2. 首次使用：先注册（填邀请码），再用同一微信登录；或已有账号在登录页绑定

### Web 后台
1. 打开 https://www.baize.gdces.cn/admin/
2. 输入用户名 + 密码
3. **「选择角色」直接留空**（系统自动识别你的岗位）——只有非常确定时才手动选

> 💡 微信注册的用户首次登 Web：先在小程序「我的 → 设置登录密码」设置密码，
> 之后即可用「用户名 + 密码」登 Web，两端数据同步。

## 1.4 岗位与权限一览

| 岗位 | 级别 | 能做什么 |
|---|---|---|
| 超级管理员 | 公司级 | 一切：立项、建号、发邀请码、解绑微信、授予公司级角色 |
| 管理员 | 公司级 | 人员审批（由超管授权） |
| 总监理工程师 | 项目级 | 本项目成员管理、派单、公司看板、系统设置、审批 |
| 总监代表 | 项目级 | 同总监（可叠加多岗） |
| 专业监理工程师 | 项目级 | 巡视、验收、旁站、见证、文书 |
| 监理员 | 项目级 | 巡视、隐患识别、工作记录（**注册开放岗**） |
| 见证员/安全监理员/资料员 | 项目级 | 各专项业务 |

> 权限是「集合」：一人可兼多岗（如总监代表兼专业监理工程师），权限取并集。

# 第二部分 · 监理人员使用指南（小程序为主）

## 2.1 工作台（底栏居中）

一句话干活的核心入口，支持语音按住说话或文字：

- 「**新建巡视记录**」→ 进入巡视填报
- 「**启动隐患识别**」→ 拍照让 AI 识别安全隐患
- 「**生成监理日志**」→ 自动汇总当天工作生成日志
- 「**知识库**」→ 跳转规范检索

## 2.2 隐患识别（底栏）

1. 现场拍照（可从工作台对话发起）
2. AI 自动识别隐患类型与依据条款
3. 确认后生成隐患记录，自动通知相关人

## 2.3 工作记录（底栏）

巡视 / 旁站 / 验收 / 见证四类记录的移动端填报：

- 新建 → 填写施工区域、部位、内容 → 保存草稿或提交
- 提交后总监/管理员在 Web 端可见

## 2.4 资料库（底栏）

项目图纸、档案、规范资料移动端查阅。

## 2.5 我的（底栏）

- **设置登录密码**：设置后可在电脑端用「账号+密码」登录同一账号（数据同步）
- 微信绑定管理：查看/解绑当前微信
- 主题配色、通知订阅、隐私指引

## 2.6 日常建议动线

```
早上到岗 → 工作台看「待办」→ 现场巡视（工作记录填报）
  → 发现隐患 → 拍照识别 → 生成隐患单
  → 下班前 → 「生成监理日志」一键汇总
```

# 第三部分 · 管理员使用指南（Web 后台为主）

## 3.1 超级管理员

### 立项与新项目启动
1. **项目管理** → 「新建项目」→ 填名称/编号/简称/地点
2. **用户管理 → 项目成员管理** → 把人员加入项目并定岗
3. （可选）**邀请码管理** → 发码给外部人员自助注册

### 账号管理
- **用户管理**：新增用户、编辑资料、授予/清除公司级角色（「公司级角色」列）
  - 公司级角色仅超管可授予；系统始终保留至少一名启用中的超管
- **邀请码管理**：新建（选岗位、次数、有效期）、停用
  - ⚠️ 邀请码决定注册者的岗位，发码前确认岗位正确
- **微信绑定管理**：查绑定点「解绑」可释放微信（人员换微信/微信号被占时用）

### 总监/管理员的权限差异（重要）
| 页面 | 超管 | 总监 | 监理员 |
|---|---|---|---|
| 新建项目 / 新增用户 / 编辑用户 / 邀请码 / 解绑微信 | ✅ | ❌（按钮隐藏） | ❌（页面不可达） |
| 项目成员管理 / 切换项目 | ✅ | ✅ | ❌ |

## 3.2 总监理工程师

- **项目成员管理**：本项目增删成员、调整岗位（每项目总监限 1 名，不可自我操作）
- **派单管理**：给监理员派任务、催办、改派、取消；接单人可拒单
- **公司看板 / AI 巡检统计**：项目数据横向对比
- **文书审批**：审批监理人员提交的文书
- **系统设置**：法规版本管理等

## 3.3 通用管理动作

| 场景 | 操作 |
|---|---|
| 新员工入职 | 发邀请码（对应岗位）→ 对方注册 → 项目成员管理加入项目 |
| 员工离职 | 项目成员管理移出 → 用户管理停用账号 → 微信绑定管理解绑微信 |
| 人员换微信号 | 微信绑定管理解绑旧微信 → 对方重新绑定 |
| 「该微信已绑定其他账号」 | 微信绑定管理解绑那个旧账号（若已是公司级账号则注册/绑定时会自动释放） |
| 注册页提示微信被占 | 同上；小程序会自动释放「小程序端不可用」的旧绑定 |

# 第四部分 · 对外汇报材料（一页纸）

## 产品定位
面向建设工程监理行业的 **AI 工程监理智能体**，以「Rokid AR 眼镜 + 微信小程序 + Web 后台」三端协同，覆盖 **巡视、验收、旁站、见证、隐患识别、文书台账** 全业务链路。

## 核心能力
1. **AI 隐患识别**：现场拍照 → 自动识别隐患 + 匹配规范条款
2. **语音驱动作业**：一句话新建巡视记录、生成监理日志
3. **两级角色权限体系**：公司级（超管/管理员）+ 项目级 7 类岗位，权限可叠加、可配置
4. **全流程留痕**：巡视/验收/旁站/见证/派单/审批/台账，数据实时同步
5. **知识库**：规范法规检索 + 知识图谱 + AI 问答
6. **多项目支持**：公司看板横向对比，人员跨项目复用

## 安全与合规
- 微信绑定「一号一号一」，绑定/解绑全程审计留痕
- 邀请码注册制，岗位由码决定，杜绝自行越权注册
- 未登录接口全量 401；低权限越权读 = 0（2026-10-10 只读权限矩阵实测 111 接口）

# 附录 A · 常见问题

**Q1：登录提示「无效角色」？**
角色下拉选择与账号岗位不符。**清空角色选择（自动识别）** 再登录即可。

**Q2：微信登录提示「该微信身份已绑定其他账号」？**
该微信绑过别的账号。若旧账号是公司级/已停用，系统会自动释放；否则联系超管在「微信绑定管理」解绑。

**Q3：微信注册的用户怎么登 Web 后台？**
小程序「我的 → 设置登录密码」设一个 ≥8 位密码 → Web 用「用户名 + 密码」登录，角色留空。

**Q4：邀请码从哪里获取？**
联系超级管理员（后台「邀请码管理」生成）。码决定你的注册岗位。

**Q5：网页刷新后 404？**
已知问题（F5 在子页面会 404），回到 https://www.baize.gdces.cn/admin/ 重新进入即可；修复排期中。

**Q6：忘记密码？**
微信已绑定的用户：小程序「设置登录密码」可免旧密码重设；未绑微信的联系超管重置。
