# 监理通 - 建筑工程监理智能体系统项目说明文档

> 更新日期：2026-07-18
> 版本：全栈实现完成版（反映 mobile-h5 独立工程 + glasses-app 业务页面补齐 + 后端 P0/P1 缺口落地）

## 一、项目概述

### 1.1 核心定位

监理通是一个面向建筑工程监理行业的智能体系统，通过 **AI 眼镜端（现场零手持作业端）、手机浏览器端（便携经办端）、微信小程序端（微信生态移动协作端）、PC Web SaaS 端（后台管控归档端）** 四端协同，为监理现场作业与管理提供一体化解决方案。系统集成视觉识别（VLM）、大语言模型（LLM）、语音识别（STT）和实时音视频（RTC）能力，贯穿现场采集、隐患识别、远程协作、文书生成、知识问答全流程。

### 1.2 四端业务定位

| 端 | 业务定位 | 核心职责 |
| --- | --- | --- |
| **AI 眼镜端** | 现场零手持作业端 | 现场画面/影像采集、全程语音操控、语音播报提醒、离线数据缓存；不部署本地模型，通过云端 API 完成安全隐患识别，适配旁站、巡视、验收等免手持场景 |
| **手机浏览器端** | 便携经办端 | 现场辅助经办核心终端：现场拍照/图片导入加水印、语音生成监理文书、隐患整改复查、规范/流程查询、接收 AI 巡检提醒、随身查看资料 |
| **微信小程序端** | 微信生态移动协作端 | 无需安装独立 App，支持拍照、录像、录音、智能体语音交互、隐患识别、整改复查、音视频通话和微信服务通知 |
| **PC Web SaaS 端** | 后台管控归档端 | 后台管理核心终端：监理文书审批、电子签章、规范库维护、验收流程模板配置、AI 巡检数据统计、批量资料导出/归档、项目全量台账管理 |

### 1.4 七大核心业务能力

1. **多渠道影像采集 + 自动水印**：眼镜端语音触发、手机端拍照/相册/微信导入、PC 端批量导入；统一水印（项目/人员/时间/位置/天气/部位/隐患标识）不可篡改
2. **建筑工程规范库**：质量验收/安全管理/施工技术/材料/消防给排水人防/地方专属规范；覆盖国标、行标、地标；PC 端维护、现场端语音查询、文书联动
3. **验收流程 AI 智能指引**：语音提问 → AI 输出标准化步骤、必查管控要点、常见违规、规范依据；PC 端可维护流程模板
4. **一键生成监理文书**：8 类文书自动填充基础字段、LLM 智能生成、审批签发、导出 PDF 支持电子签名
5. **隐患整改闭环**：AI 识别或人工提报 → 语音一键开具整改通知单 → 推送施工方 → 整改影像上传 → 监理语音复查 → 闭环台账联动
6. **四端统一台账与归档**：8 类台账自动汇总，按时间/部位/隐患类型/文书编号全文检索，PC 端批量导出/打印/电子签章/分类归档
7. **云端 AI 安全隐患智能识别**：眼镜端不部署本地模型，按频率采集图片→上传云端 API→大模型识别→结构化结果回传→语音播报+震动+自动取证+联动整改
8. **微信小程序实时协作**：调用手机摄像头和麦克风完成拍照、录像、录音及一对一音视频通话，现场可远程连线总监/专监协同处置

### 1.5 三端实现完成度

> 本节反映两阶段补齐开发后，眼镜端 / 手机端 / PC 端三端的实现进度。微信小程序端作为第四端单独说明。

| 端 | 实现完成度 | 已实现核心能力 | 待完善项 |
|---|:---:|---|---|
| **AI 眼镜端**（`glasses-app/`） | ~90% | 网络层（OkHttp+JWT 拦截器+10 数据模型）、相机层（CameraX+按频率采集+ImageUploader）、语音层（ASR+VoiceCommandRouter+TTS）、数据层（Room+WorkManager SyncWorker）、9 大业务页面（登录/菜单/工作记录/文书/隐患/任务/知识/巡检/签章）、WatermarkOverlay 水印+SHA256、InspectionBus 跨页通信 | 真机按频率自动采集需随 Rokid 宿主相机 API 联调；提交智能体商店审核 |
| **手机浏览器端**（`mobile-h5/`） | ~95% | Vue 3.5+Vant 4+Pinia+PWA 独立工程；23 个业务页面（登录/工作台/工作记录/影像/隐患/文书/知识/任务/巡检/台账/我的）；IndexedDB 离线队列；TabBar 4 项导航；JWT 拦截器；路由守卫 | 生产环境 PWA 配置优化 |
| **PC Web SaaS 端**（`web-admin/`） | ~95% | 六入口导航（工作台/现场识别/工作记录/信息库/待办中心/系统设置）；工作台对话式图片隐患识别；AI 巡检统计归入工作记录；信息库合并知识文档与知识图谱；服务端模型配置加密持久化 | 生产域名与外部模型供应商联调 |
| **微信小程序端**（`wechat-miniprogram/`） | ~70% | 9 个页面（登录/工作台/智能体/采集/工作记录/隐患/通讯录/通话/待办）；services（auth/request/rtc/signaling/upload/uploadQueue） | 待配置企业 AppID/Secret、合法域名及 RTC 服务商；双真机联调；微信审核发布 |

**三端协同实现要点**：

- **统一后端**：四端共享同一套 `cloud-backend` REST API（20 路由模块）+ MySQL 数据库 + AI 服务（VLM/LLM/STT）
- **统一认证**：JWT + RBAC 四角色权限矩阵，四端共用同一套认证体系
- **实时同步**：WebSocket（`/api/ws/{user_id}`）11 处业务场景实时推送，多端在线同步
- **离线容灾**：眼镜端 Room+WorkManager、手机端 IndexedDB 离线队列，联网后自动补传

### 1.6 价值主张

- **现场减负**：眼镜端语音操控 + 拍照取证，解放双手，快速创建工作记录
- **AI 赋能**：VLM 自动识别隐患，LLM 自动生成文书与答疑，降低重复性工作
- **闭环管理**：从派单到执行到审批到归档全流程线上化，数据可追溯
- **四端协同**：眼镜/手机浏览器/微信小程序/PC 各司其职，现场轻量化、微信内快速协作、后台全功能
- **弱网可用**：现场端支持弱网/离线缓存，联网后自动同步，不丢失巡检与影像数据

### 2.2 眼镜端（Rokid Glass App 智能体）

- **部署方式**：在 Rokid Glass App 智能体商店上架，用户在眼镜内直接安装使用
- **通信方式**：眼镜通过 WiFi/5G 直连后端 API，不再需要手机中转
- **核心能力**：语音操控、语音播报、拍照采集、隐患识别、界面展示、工作记录创建、接收派单通知
- **定位**：现场作业轻量化入口，解放双手，快速完成采集与记录

### 2.3 手机浏览器端（独立 PWA 工程）

- **部署方式**：独立 Vite PWA 工程（`mobile-h5/`，端口 5174），从原 web-admin 移动适配拆分为独立项目
- **技术栈**：Vue 3.5 + Vant 4 + Pinia + Vue Router + axios + @vueuse/core + idb + vite-plugin-pwa
- **通信方式**：HTTPS 调用后端 REST API；调用手机本身或蓝牙耳机的麦克风和扬声器进行语音端到端交互
- **核心能力**：23 个业务页面（登录/工作台/工作记录/影像/隐患/文书/知识/任务/巡检/台账/我的）、TabBar 4 项导航、IndexedDB 离线队列、PWA 支持、JWT 拦截器、路由守卫
- **定位**：无眼镜场景下的现场替代方案，兼顾便携与功能完整

### 2.4 PC Web SaaS 端（管理后台）

- **部署方式**：通过 PC 端 Web 浏览器访问 SaaS 管理后台
- **核心能力**：全部业务功能管理、系统设置、用户管理、眼镜模拟器（保留测试功能）、智能监理助手、数据导出
- **定位**：管理决策与全功能操作中枢，覆盖所有后台管理需求

### 2.5 微信小程序端（原生小程序）

- **部署方式**：发布至微信小程序平台，用户通过搜索、扫码或分享卡片进入
- **通信方式**：HTTPS 调用业务 API，WSS 接收呼叫信令，RTC 服务承载实时音视频
- **核心能力**：微信登录绑定、智能体文字/语音交互、拍照、录像、录音、隐患识别、工作记录、整改复查、音视频通话、服务通知
- **定位**：微信生态内的快速现场采集与远程协作入口

### 2.6 技术架构

- **后端**：FastAPI + MySQL + SQLAlchemy 异步 ORM
- **前端**：Vue 3 + TypeScript + Element Plus + Pinia
- **眼镜端**：Rokid Glass App 智能体平台
- **微信小程序端**：原生小程序 + TypeScript；相机/录音原生 API；RTC 推拉流组件
- **AI 服务**：华工 VLM（云端）+ Ollama LLM（本地优先，AI Center LLM 降级）+ faster-whisper STT（本地）
- **音视频服务**：合规 RTC 服务，后端签发短期凭证并管理房间、信令与审计

## 五、核心业务流程

### 5.1 工作记录流程

记录分四类（巡视、验收、见证、旁站），状态流转统一为：草稿 -> 已提交 -> 已审批 -> 已归档。

```
[现场采集]
   │ (眼镜拍照/手机拍照)
   ▼
[创建草稿] ── 自动叠加水印 ── 关联项目/人员/时间/位置
   │
   ▼
[提交]  ── 状态: 已提交
   │
   ▼
[审批]  ── 总监/总代/专监(按权限) ── 状态: 已审批
   │       │
   │       └─ 驳回 -> 回到草稿
   ▼
[归档]  ── 状态: 已归档，台账自动更新
```

**实现状态**：✅ 已实现。后端 WorkRecord 模型含 reject_reason/approved_by/approved_at 审批字段；独立 submit/approve/reject/archive 接口；四端覆盖（PC 端 Inspection/Acceptance/Witness/Station.vue + 眼镜端 WorkRecordList/Create/Detail + 手机端 WorkRecordList/Create/Detail）；WebSocket 实时推送审批结果。

### 5.2 隐患识别与整改闭环

现场拍照后 VLM 自动识别隐患，生成整改通知单，跟踪整改直至复查闭环。

```
[现场拍照] (眼镜/手机)
   │
   ▼
[VLM 识别] ── 华工云端模型，识别安全隐患
   │           │
   │           └─ 命中隐患 -> 自动取证（图片哈希 + 水印 + 时间戳）
   ▼
[生成整改通知单] ── 关联项目/位置/隐患类型
   │
   ▼
[派发整改] ── 推送给责任方
   │
   ▼
[整改执行] ── 责任方上传整改后照片
   │
   ▼
```

## 七、数据安全与合规

### 7.1 水印防篡改

- 所有现场采集图片自动叠加水印，包含项目、人员、时间、位置、天气、隐患标识
- 水印信息不可后期移除，保障影像资料真实性

### 7.2 JWT 认证

- 全部 API 接口采用 JWT Token 认证
- Token 包含用户身份与角色信息，支持多端会话管理
- 四端（眼镜/手机浏览器/微信小程序/PC）统一认证体系

### 7.3 RBAC 权限控制

- 基于角色的访问控制（RBAC），四种业务角色按权限矩阵分配功能，`admin` 为超级管理员账号
- 接口级权限校验，越权访问拒绝并记录日志
- admin 超级管理员拥有全部权限，可任意角色登录

### 7.4 影像取证哈希

- 采集图片在叠加水印后计算哈希值并持久化存储
- 哈希值作为影像取证依据，支持后续完整性校验
- 防止图片被篡改或替换，保障监理证据链可信

### 7.5 数据合规

- 现场采集数据与后台管理数据分离存储，按项目隔离
- 工作记录、隐患整改、文书签发全流程留痕，可追溯
- 支持数据导出（Excel/PDF）满足归档与审计要求
