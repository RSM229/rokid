## 1. 接入过程

### 1.1 第三方系统接入方式

**接入准备：**
- A. 提供系统名称、服务窗 LOGO、服务窗主页 URL（每个服务窗需独立 URL 入口）。
- B. 若需将通讯录集成到框架：提供服务窗组织通讯录 LOGO 和访问地址。
- C. 用户与服务窗关系类型（四选一）：
  1. 显示服务窗，用户可直接进入；
  2. 显示服务窗，用户需申请加入（需配置申请加入页面 URL）；
  3. 显示服务窗，弹框提示配置文案；
  4. 非服务窗用户，不显示该服务窗。
- D. **必须**按「修改手机号」接口标准实现，并提供接口服务地址（对应 4.3 的实现义务）。

**接入流程：**
1. 第三方系统注册 → 管理员发放 **AppKey、AppSecret、windowsId** 三个参数。
2. 第三方应用用户同步（可选）：存量用户可调「用户批量同步」接口一次性同步给框架；或让用户自行在框架 APP 注册，进入服务窗时由服务窗判断并调用同步接口绑定关系。
3. 框架新用户进入服务窗：服务窗自行判断是否接入；可通过「根据 token 查询用户信息」获取用户资料，在第三方系统内注册后，调用户同步接口向框架同步「用户-服务窗」关系。
4. 用户信息修改：框架支持用户修改手机号，并通知相关服务窗。

## 2. 单点登录（SSO）

**时序：** 用户在框架（APP 端 / PC 端）进入服务窗 → 第三方前端通过 SDK 获取框架 token：
- APP 端：app-sdk 获取 token；
- PC 端：`const token = umPcSdk.getData('token')`（无需引用脚本，`umPcSdk` 直接注入 window）；
- web 端同 PC，但需先引入脚本：
  - 测试：`http://183.6.48.123:30680/pcsdk/pcsdk.min.js`
  - 生产：`http://sjt.gz-szcj.com:8000/pcsdk/pcsdk.min.js`

→ token 传给第三方后端 → 调框架 API「查询服务窗下的登录凭证」（返回登录凭证，默认用户手机号）→ 校验用户是否已存在：
- 存在 → 返回第三方系统 token，SSO 成功；
- 不存在 → 调「根据 token 查询用户信息」拿手机号/姓名创建新用户 → 调「用户批量同步」绑定用户与服务窗关系 → SSO 成功；拒绝场景提示用户先注册。

## 3. 开放 API

### 3.1 公用 Head 头（签名认证）

OpenApi 授权：用 `Nonce`、`CurTime`、`AppKey` 做 SHA1 签名，放入 `CheckSum` 头，服务端校验。

| 参数 | 说明 | 类型 | 可空 |
|---|---|---|---|
| Nonce | 随机数（最大 36 字符） | String(36) | N |
| CurTime | 当前 UTC 时间戳（1970 起秒数，字符串） | String | N |
| AppKey | 框架分配的 appkey | String(36) | N |
| CheckSum | `SHA1(AppSecret + Nonce + CurTime)`，**小写**十六进制 | String | N |

Java 生成示例：`encode("sha1", appSecret + nonce + curTime)`（标准 SHA1 → 小写 hex）。

### 3.2 用户相关 API

#### 3.2.1 根据 token 查询用户信息
- `GET {API_URI}/yjy/external/open/get/user/basic/info/by/token`
- 头：公用 Head + `Authorization: 用户token`
- 响应 data：`phone / userName / userId / account / avatar / createTime` + `authInfos[]`：
  - `authType`：0-局统一支撑平台；1-省统一身份认证平台；2-支付宝人脸实名认证
  - `userInfo`：authType=0/1 时为 **AES 加密 json**（secretKey=用户 token，见附录B）；authType=2 时为明文 json（alipayUserName/gender/certified/faceAuthStatus/certifyTime）

#### 3.2.2 用户批量同步（绑定用户与服务窗关系）
- `POST {API_URI}/yjy/external/open/user/batch/add`；头：公用 Head + `windowsId`
- 体：`{ batchId, user: [{ phone(String16), userName(String8), hasAddressBook(1/0) }] }`

#### 3.2.3 查询批量同步失败数据
- `GET {API_URI}/yjy/external/open/sync/failure/list?batchId={batchId}`
- 响应 data：失败用户 `{phone, userName}`（userName 最长 8 字符且只能是中文）

#### 3.2.4 根据手机号查询用户基本信息
- `GET {API_URI}/yjy/external/open/get/user/basic/info?phone={phone}`
- 响应 data：`phone / userName / userId / account / avatar / createTime`

#### 3.2.5 用户解绑服务窗
- `POST {API_URI}/yjy/external/open/user/unbind/windows`；头：公用 Head + `windowsId`
- 体：`{ phone }`

### 3.3 服务窗相关 API

#### 3.3.1 查询服务下所有服务窗信息
- `POST {API_URL}/yjy/external/open/get/service/info`
- 体：`{ serviceId, page: { pageNum, pageSize } }`
- 响应：`list[{ windowsId, windowsName, icon, domain, contactDomain, indexUrl }]` + 分页

#### 3.3.2 查询服务窗下的登录凭证（SSO 第二步）
- `POST {API_URL}/yjy/external/open/get/windows/loginCredentials`
- 头：公用 Head + `Authorization: 用户token`
- 体：`{ windowsId }`
- 响应：`{ windowsId, loginCredentials }`（默认用户手机号）

### 3.4 IM 相关 API（服务窗消息）

#### 3.4.1 服务窗发送消息
- `POST {API_URL}/yjy/external/open/im/sendAppMsg`；头：公用 Head + `windowsId`（发送方服务窗）
- 体：`title(String64) / content(String512) / coverUrl(可选) / toUsers(逗号分隔，不传=服务窗全体) / andriodJumpUrl / iosJumpUrl / pcJumpUrl`
- 响应 data = `msgId`

#### 3.4.2 服务窗查询消息发送记录
- `POST {API_URL}/yjy/external/open/im/getAppMsgs`；头：公用 Head + `windowsId`
- 体：`{ msgId }`；响应：消息列表（含 msgId/title/content/coverUrl/各端 jumpUrl/createTime）

## 4. 第三方系统集成 API（可选，第三方需提供的服务端接口）

### 4.1 人员组织树列表
- 第三方实现 `POST {API_URI}/yjy/cloud/external/direct/org/and/user/list`（头含 windowsId）
- 入参：`orgId`（不传=根节点）、`Phone`
- 出参：`orgList[{ orgId, orgName, orgDesc, peopleCount }]` + `userList[{ phone, userName, avatar, userId, position }]`

### 4.2 人员信息列表
- 第三方实现 `POST {API_URI}/yjy/cloud/external/user/list`
- 入参：`searchValue`（姓名/手机号模糊）、`maxCount`（默认 3）
- 出参：用户列表（orgId/orgName/phone/userId/userName/position）

### 4.3 修改框架用户手机号（接入准备 D 的必实现接口）
- 第三方实现 `POST {API_URI}/yjy/cloud/external/user/info/update`
- 入参：`oldPhone`、`userName`（可选）、`newPhone`

## 附录 B 解密算法（authType=0/1 的 userInfo）

- secretKey = **用户 token 的值**（超过 16 位取前 16 位）
- 算法：**AES/ECB/PKCS7**（Java 侧 `Cipher.getInstance("AES")` 默认 ECB；C# 侧显式 `CipherMode.ECB, PaddingMode.PKCS7, KeySize=128`），密文 Base64 编码，解密后去掉空白字符。
- ⚠️ Python 等价实现：`AES.new(secretKey[:16].encode(), AES.MODE_ECB).decrypt(base64.b64decode(value))` 后 `unpad` PKCS7。
