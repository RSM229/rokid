# 监理系统数据采集接口对接开发手册

## 通用说明

### 请求方式

所有接口统一使用 **POST** 请求。

### 接口地址

接口路径统一格式为：

```
POST http://{ip:port}/tenantgz/e-api/ods/push/{接口标识}
```

例如：

```
POST http://{ip:port}/tenantgz/e-api/ods/push/patrol_record
```

### 请求头

| 参数名 | 必填 | 说明 |
|--------|------|------|
| Authorization | 是 | Bearer Token |
| appCode | 是 | 应用注册的编码数值 |
| X-Data-Source | 是 | 数据来源，固定为：jlt |
| Content-Type | 是 | 固定为：application/json |

### 请求体格式

所有接口请求体统一包装在 `data` 字段中：

```json
{
  "data": {
    "id": 1,
    "projectCode": "PRJ202600000854",
    "...": "..."
  }
}
```

### 响应参数

| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，0 表示成功 |
| msg | String | 提示信息 |
| data | Object | 推送结果详情 |
| data.entityType | String | 实体类型 |
| data.srcId | String | 源系统原始ID |
| data.code | String | 数据中台编码 |
| data.status | String | 处理状态：INSERT / UPDATE / DUPLICATE_INSERT / DUPLICATE_UPDATE |

| patrolStatus | String | 否 | 巡视情况；扩展写入 `record_content` |
| foundProblems | String | 否 | 发现问题；扩展写入 `record_content` |
| handlingStatus | String | 否 | 处理情况；扩展写入 `record_content` |
