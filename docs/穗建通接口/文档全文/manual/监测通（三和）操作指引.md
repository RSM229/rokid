# 一、PC端功能详解

## 1、进入系统-PC端

人员需要先在穗建通注册号账号和创建对应的企业和基坑监测项目，然后进入项目工作台，点击“监测通（三和）”进入

通过"方案-人员-设备"三要素的配置实现技术准备就绪，构成监测实施的基础条件。其中监测人员和设备直接获取穗建通登记的信息。

## 3、现场监测：实施阶段

实施阶段配置是监测工作的技术核心，通过监测项目设置、报警阈值配置、断面及测点参数配置等环节，构建完整的监测技术方案。系统支持手动与自动两种监测方式，报警设置支持多个阈值体系，满足不同安全等级的管控需求。

**（1）监测项目设置**

选择监测类别（如支护结构深层水平位移、周边地表竖向位移）、监测项目（如围护墙深层水平位移）、监测对象（具体围护墙段），指定监测方式为手动或自动。

![](/images/images-manual-jct/image_008.png)

![](/images/images-manual-jct/image_009.png)

**（2）报警阈值配置**

为每个监测项目设置累计变化阈值（预警值/报警值/控制值，单位mm）与变化速率阈值（预警值/报警值/控制值，单位mm/d），建立分级预警机制。

![](/images/images-manual-jct/image_010.png)

![](/images/images-manual-jct/image_011.png)

![](/images/images-manual-jct/image_012.png)

**（3）断面设置**

水平位移类项目需定义虚拟断面（起始点、终止点、方向），手动监测需配置测点编号与初始累计值，自动监测需关联采集仪编号与通道号。

![](/images/images-manual-jct/image_013.png)

![](/images/images-manual-jct/image_014.png)

![](/images/images-manual-jct/image_015.png)

**（4）测点设置（手动监测方式的测点）**

根据监测项目的监测方式区分，手动设置项目的测点信息，按实际设置，否则会影响后续数据计算。

![](/images/images-manual-jct/image_016.png)

![](/images/images-manual-jct/image_017.png)

设置自动监测方式的监测项目的测点信息，按实际设置，否则会影响后续数据计算。

![](/images/images-manual-jct/image_020.png)

![](/images/images-manual-jct/image_021.png)

![](/images/images-manual-jct/image_022.png)

**（6）监测设备及监测频率设置**

设置监测项目对应的监测设备和监测频率，不同的监测项目，设置内容有所不同。

**（5）数据上传：全站仪和水准仪**

APP端支持全站仪、水准仪等传统测量设备的无线数据采集，通过蓝牙协议与测量设备建立连接，自动获取测量数据并解析计算，实时回传至PC端，实现外业测量到内业管理的无缝数据流转。

**（6）数据上传：测斜仪与判稳配置**

"测斜仪数据采集支持深层水平位移监测，关键创新在于'判稳配置'机制：针对不同厂商测斜仪的技术差异，可配置绝对值或百分比判稳偏差，确保探头稳定后再记录数据，避免扰动误差。"

**（7）数据上传：振弦读数仪（南京斯比特）**

振弦读数仪用于支撑内力、锚索内力、土压力等应力类监测，APP通过蓝牙读取设备存储的分区数据文件，自动将频率值换算为应力值，实现应力监测数据的现场自动计算与实时上传。

**（8）监测巡检：现场安全巡查记录**

监测巡检模块实现了基坑现场安全状况的数字化巡查，通过标准化的检查项与图文记录，替代传统的纸质巡检表。系统记录施工进度、天气状况、巡检结论，支持状态标记与问题描述，形成连续的现场安全档案，与自动化监测数据互为补充，构建"仪器监测+人工巡查"的双重安全保障体系。
