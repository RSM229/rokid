# 监理小助手 P0（全站悬浮球）— 2026-11-11

## 做了什么

在 web-admin 布局层挂了一个全站悬浮球，接后端已有 Agent（`/api/agent/chat`），
不另起对话引擎。P0 范围：对话、结果卡、页面动作、历史会话、快捷键。

- 悬浮球固定在右下角；点击展开 384px 面板；`Ctrl/⌘ + K` 唤起，`Esc` 收起
- 空状态给四条例句（打开台账 / 今天的记录有几条 / 生成今天的监理日志 / 未整改的隐患）
- 助手回执渲染：纯文字（pre-wrap）、结果列表行、链式动作、撤销、chips、图表卡（预留）
- 页面动作：后端 `navigate` 返回的小程序路径（`/pages/...`）在前端映射成 web 路由
- 历史会话：面板内切换，按 user + project 隔离；切项目自动开新会话
- 视觉约束：无蓝/紫/渐变，无阴影、无大横幅、无表情，卡片全部做成列表行 + 细分割线

## 踩过的坑

1. **Rolldown 分块**：图表组件若被静态 import 进布局层，`rolldown-runtime` chunk 会消失，
   入口初始化顺序错乱 → 全站白屏（`TypeError: e is not a function`）。
   改为 `defineAsyncComponent(() => import('./AssistantChart.vue'))` 后恢复。
2. **bind mount**：见上，dist 目录只可原地覆盖。
3. **nginx 容器重建**：官方镜像 entrypoint 的 `apk manifest` 在本机会卡住，
   容器重建后 nginx 不启动；`pkill -9 apk` 后可正常拉
   （重建还会丢 `docker cp` 进去的 `/lab/`，已从 `/home/baize/jl-field-test` 恢复，
   并留了主机副本 `/home/baize/rokid_glass/lab`）。
4. **conversation_id 必传**：后端 `conversation_id` 缺省为 `None` 时不落展示历史，
   Web 端每次请求都带客户端生成的 id，历史才可用。

## P0.5（2026-11-11 晚，同日追加）

### 1. 旧工作台对话已下线

`Dashboard.vue` 移除整块关键词对话（含指令路由表、监理日志弹窗、层级面包屑），

### 2. 图片发送（迁移旧工作台能力，并接进 Agent）

- 输入框左侧「图片」按钮 → 选图（jpg/png/webp，≤10MB）→ 输入框上方缩略图预览
- 发送后：先调 `POST /api/hazard/detect`（VLM，超时放宽到 **180s**：实测 15~140s 不等）
  → 识别文本作为 `material` 传给 `POST /api/agent/chat`，Agent 基于识别结果继续回答/建档
- 消息里保留原图缩略图（仅当次会话，历史回看只显示文字）
- VLM 供应商偶发 502/超时，已把后端 `detail` 透到界面（不再只显示"识别失败"）

### 3. 模型展示（澄清：不是切换器）

旧工作台的「模型」是只读 `el-tag`，不是下拉切换。现在面板头部显示当前文本模型
（`GET /api/local/llm/status`，如「阿里云 / qwen3.7-plus」），
改模型仍在「系统设置 → 模型调用设置」。

### 4. 超时修正

- `agent/chat`：30s → **180s**（工具轮建记录/出稿可能 30~60s）
- `hazard/detect`：30s → **180s**
