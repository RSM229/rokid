## 本轮新增功能（重点测）

### 「我」页面新增：设置登录密码
- 入口：`pages/mine/index` 微信绑定区块后
- 交互：点击 → `wx.showModal({editable:true})` 输入新密码 → 长度校验（≥8 位）→ 调 `POST /miniprogram/auth/password`
- 后端：已绑微信免旧密码；未绑必须提供旧密码
- **目的**：微信一键登录用户此前从未设过密码，无法登 Web 端；设置后可用「账号+密码」登 Web

### 注册流程（强化）
- 强制邀请码（`invite_codes.role` 决定角色，前端传值被忽略）
- 白名单：`PUBLIC_REGISTRATION_ROLES=inspector,special_supervisor`
- 微信已绑公司级账号 → 释放旧绑定并接管（不再死局）

### 登录流程
- 已绑定有效项目级账号 → 直接发 token
- 已绑定**公司级**账号 → 403（`_token_response` 拦截）→ 前端改走绑定表单
