## 一、opencode 会话问答记录

### Q1：我们做了什么到现在？（会话恢复）

**A：** 当前焦点在「监理通」全栈系统的收尾与巡检联动，关键进展如下：

- **华工隐患识别 VLM 链路打通**：`model_config_service.py` 修复 vlm 分支 options（原来缺 org_id），`config.py` 增加 `vlm_input_name`；实测 `POST /api/hazard/detect` 返回 200 + 结构化结果。
- **隐患管理集成工作记录**：`pages/work` 增加「隐患」tab（TYPE_TABS 加 `{label:'隐患', key:'hazard'}`），支持预览/上传整改影像/生成整改单/复查合格-驳回/联系协作/分享。
- **整改单闭环**：
  - 监理文书页加筛选（全部/整改通知单/待审批），并修复 `result.items` 与后端数组响应的不匹配 bug（`Array.isArray` 兼容）。
  - 生成整改单前弹日期 sheet 选期限（`?deadline=`，默认 7 天）→ 成功后跳转文书详情页。
  - 详情页「生成 PDF」「审批同意/驳回」按钮。
  - 文书内容全中文（`CONTENT_LABELS` 中英映射，过滤无意义英文 key）。
- **PDF 中文字体修复**：reportlab 不支持 CFF/PostScript 轮廓（NotoSansCJK 注册报错），改用 TrueType 字形中文字体（DroidSansFallbackFull.ttf）注册 NotoSC/NotoSC-Bold。
- **知识库 Word 查看修复**：容器内 `knowledge.py` 是旧版本缺 `/regulations/content` 端点导致详情页 404；重新部署新版 + `docker restart` 后 content/download 均 200；并修复 download 的 MIME（docx/xlsx 返回正确 content-type），前端 `wx.openDocument` 传正确 `fileType`。

### Q2：查看 RPD 文档，结合小程序看还缺什么功能没有展示？

**A：** 按 RPD 第 19 章（微信小程序端）及各功能章节，对照当前小程序页面逐条核对，梳理出**遗漏/缺口**：

| # | 缺口 | 说明 |
|---|------|------|
| 1 | **无独立"台账查询"入口**（最明显） | RPD 第 9 章、附录 A 明确标注"手机端台账查询"为实现，但小程序个人中心没有任何台账查看入口；agent 的"查台账"指令只跳工作记录页，没有台账实体页。 |
| 2 | **监理周报/月报、验收记录文书类型缺失** | agent 页 `docTypes` 只列了巡视/监理日志/旁站/见证/监理通知单/整改单，缺周报、月报、验收记录。 |
| 3 | **派单"发起"缺专门 UI** | 只能通过智能体对话触发 `openTaskForm`，首页快捷区没有显式"发起派单"入口（todo 仅展示"我收到的"）。 |
| 4 | **验收记录未联动生成"省统表验收记录文书"** | 工作记录"验收"能建记录，但未看到像隐患→整改单那样的"验收→验收文书"跳转联动。 |
| 5 | **无通知中心消息列表页** | 首页只显示数字统计，没有通知列表页；WebSocket 录到推到但无查询面。 |
| 6 | **app.json 未配置原生 tabBar** | 底部是自己画的假 tabbar，`todo` 标签叫"待定"、`knowledge` 叫"资料库"，命名与业务不符。 |

**建议优先级**：台账查询页 > 周报/月报文书 > 派单发起入口 > 通知中心 > 验收文书联动。

## 二、微信小程序全部页面/功能说明

> 前端：微信原生小程序 + TypeScript；后端接口前缀 `/api`，baseURL 见 `config.ts`。

### 全局与路由

- `app.json`：注册 19 个页面路由；声明摄像头/录音/定位权限（`scope.camera`/`scope.record`/`scope.userLocation`）与 `requiredPrivateInfos`（getLocation/chooseLocation）；未配置原生 tabBar（底部为自定义假 tabbar，入口在 home 页）。
- `services/auth.ts`：`loginWithWechat`（`wx.login` 换取微信身份 + bind_token）、`bindAccount`、`register`。
- `services/request.ts`：JWT 请求封装（带 `Authorization: Bearer`）。
- `services/upload.ts` / `uploadQueue.ts`：图片/视频/音频/巡检采集上传；弱网/失败入离线队列（`UploadError.retryable` 区分）。
- `services/rtc.ts` / `signaling.ts`：音视频通话 API + WebSocket 在线信令订阅。
- `services/notice.ts`：微信订阅消息授权/预加载模板/订阅状态回传。
- `services/session.ts`：登录态/用户信息缓存。

### 页面清单

#### 1. `pages/login` — 登录 / 微信绑定
- 「微信登录」一键走 `loginWithWechat`；可手动输入用户名/密码 + 选角色后「确认绑定并登录」。
- 覆盖分享卡片进入时的登录流转。

#### 2. `pages/register` — 注册
- 用户名/真实姓名/角色/手机号/密码注册；先取微信身份，未绑定则注册并绑定，已绑定则提示直接登录。
- 密码最少 8 位、两次一致校验。

#### 3. `pages/home` — 工作台（首页 + 自定义 tabbar）
- 快速操作 9 宫格：监理智能体 / AI隐患识别 / 现场采集 / 音视频通话 / 隐患管理 / 监理文书 / 工作记录 / AI巡检 / 规范知识库。
- 统计卡片：待接任务 / 待处理隐患 / 工作记录（未处理）。
- 通知：WebSocket `signaling.connect()` + 15s 轮询 `/task/notifications`，弹订阅消息开通引导（派单/催办/审批/隐患 4 模板）。
- 底部 tabbar：工作台 / 工作记录 / 待定 / 资料库 / 我（自定义，非原生）。

#### 4. `pages/agent` — 监理智能体（核心入口）
- 文字问答 + 按住说话 STT（上传音频 → 文本）→ 自动发送；答案文字展示 + TTS 语音播放。
- 指令路由：工作记录/巡视/验收/旁站/见证/隐患识别/隐患列表/生成监理日志/台账/知识库/文书审批/待办任务/通讯录/AI巡检/规范查询/拍照/返回 等，支持多端点进。
- 多模型切换：Qwen3.8（chat）/ 华工隐患大模型（hazard）。
- 知识范围选择：全部 / 省统表 / 安全监理用表 / 知识图谱。
- 图片识别：选图上传 `/hazard/detect` 结构化展示隐患识别结果。
- 命令内置表单：新建工作记录（4 类）、生成监理日志（聚合当日工作+隐患）、发起派单（`/task`）、创建/润色文书（`/document/create`、`/document/generate-with-llm`）。
- 项目：创建/切换项目；对话历史存储/恢复/删除/新对话。

#### 5. `pages/capture` — 现场采集（拍照/录像/取证）
- 摄像头拍照、连续录像（记录时长）、相册/相机选图选视频；前后摄切换。
- 自动补字段：来源(miniprogram)、部位、位置(GPS)、天气、施工内容、业务关联(business_type/id)。
- 上传后服务端加水印 + SHA256 哈希；AI 识别模式（`mode=hazard`）触发隐患识别。
- 弱网/失败入 `uploadQueue` 离线队列，支持一键重试；成功后跳隐患详情。
- 关联入口：工作记录采集 / 隐患整改影像 / todo 任务采集（`gdjl_capture_context`）。

#### 6. `pages/inspection` — AI 安全巡检
- 启停巡检会话（选频率 5/10/30/60 秒）、历史列表。
- 拍摄/相册采集照片 → `uploadInspectionCapture` → 服务端识别隐患 + 自动匹配规范；检测到隐患震动 + 提示，可跳隐患详情。

#### 7. `pages/work` — 工作记录
- TypeTabs：巡视 / 旁站 / 验收 / 见证 / 其他 / 隐患；时间筛选（今天/本周/本月/自定义）。
- 新建四类工作记录（按权限过滤）；创建后弹窗引导去采集；旁站结束逻辑（进行中→PUT 结束）。
- 编辑二级操作：`/form-docs/record/{id}/forms` 生成省统表 / 上传下发到角色 / 转发给成员（`/work-record/{id}/share`）。
- **隐患 tab**：预览图片、上传整改影像、生成整改单（弹期限 sheet → `/hazard/{id}/create-rectification-doc?deadline=` → 跳文书详情）、复查合格-驳回（`/hazard/{id}/recheck`）、联系协作（`relatedType=hazard`）、分享。
- 通话关联：联系协作跳 `contacts?relatedType=hazard|work_record`。

#### 8. `pages/hazards` — 隐患管理
- 隐患列表（图片预览、证据聚合）；生成整改单（期限选择）、上传整改影像、复查合格-驳回、联系协作、分享卡片。

#### 9. `pages/documents` — 监理文书列表
- 筛选：全部 / 整改通知单（doc_type=安全隐患整改通知单）/ 待审批（status=待审批）。
- 兼容后端数组响应（`Array.isArray`）与 `{items}` 两种返回。

#### 10. `pages/documents/detail` — 文书详情
- 内容全中文化展示（`CONTENT_LABELS` 中英映射，过滤无意义英文 key，数组 join）。
- 「生成 PDF」调 `/document/{id}/export-pdf` 后自动 `openDocument`（PDF 中文字体修复）。
- 「下载 PDF」`/download-pdf`。
- 审批：canApprove=状态待审批 且（角色=总监理工程师 或权限含 document_approve），`/approve` 通过、`/reject{reason}` 驳回。

#### 11. `pages/knowledge` — 规范知识库 + 验收指引
- 双模式：规范库检索 / 验收指引（`/knowledge/acceptance-guide`）。
- 规范库：列表（省统表/安全监理用表分类）、`/regulations/content` 查看全文（docx/xlsx 现场解析）。

#### 12. `pages/knowledge/detail` — 知识库文档详情
- 加载全文（content 接口，容器旧版缺端点 bug 已修复）；下载原文件（`/regulations/download/{filename}`），按扩展名给 `wx.openDocument` 传 fileType（doc/xls/pdf）。

#### 13. `pages/todo` — 待办/派单（收件人视角）
- 状态筛选：全部/待接单/已接单/进行中/已完成/已拒单。
- 操作：接单（订阅消息授权）、拒单（填原因）、开始执行、完成（填回执）。
- 关联任务采集、联系协作、分享派单卡片（`/pages/todo?id=` 聚焦）。

#### 14. `pages/contacts` — 通讯录 / 发起音视频通话
- 项目成员列表（在线状态）；发起音频/视频通话（可带 relatedType/relatedId）；无 RTC 配置时 mock。

#### 15. `pages/call` — 通话页
- 来电/去电；接听/拒绝/挂断；静音/摄像头开关/前后切换/扬声器切换；状态：等待接听/通话中/已拒绝/已结束/未接听/失败；网络弱提示；LivePusher/LivePlayer 媒体流；WebSocket 信令订阅远端状态。

#### 16. `pages/mine` — 个人中心
- 用户信息展示；眼镜登录二维码（`/auth/glasses/qr-create` → canvas 绘制二维码）；退出登录（关信令 + 清 session）。
- （注：这里**没有台账查询/通知列表入口** —— 见第一部分的缺口清单）

#### 17. `pages/dashboard` — AI 巡检数据看板（代码存在，未注册进 app.json 路由）
- KPI：今日巡检/今日隐患/待接任务/待处理隐患；7 天巡检隐患趋势折线；工作记录 pending 条形图；隐患类别占比环形图（conic-gradient）。
- 数据源：`/task/todo-stats`、`/work-record/stats`、`/inspection/stats`、`/inspection/trend?days=7`、`/inspection/category-distribution`。
